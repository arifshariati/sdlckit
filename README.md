# sdlckit

Claude Code, engineered. An opinionated software delivery workflow for Claude Code, built on TypeScript and Node.js.

> Status: private, pre-v1. Not yet ready for public use.

## Planned

- A single workflow: plan, implement, validate, review, fix, PR-ready
- A cost guard that reports token use per stage, with opt-in budgets
- An installer CLI (`npx sdlckit`) and a Claude Code plugin marketplace
- Backend, frontend, CI/CD, and infrastructure rulebooks, held to HashiCorp and AWS best practices

See [docs/decisions.md](docs/decisions.md) for the design decisions behind the project.
